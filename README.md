## Contenido
En este repositorio está el proyecto de Hundir la Flota, realizado con Python, Numpy y pygame (opcional)

## Librerias necesarias
- Time
- OS
- Numpy (instalación necesaria)
- pygame-ce (instalación necesaria)

## Como ejecutar 

>[!NOTE]
> Puedes ejecutarlo tanto en una terminal del sistema como en la terminal de Visual Studio Code	

Para ejecutar el proyecto, simplemente carga el archivo "main.py" en un terminal.
En caso de querer jugar con interfaz grafica (con pygame), carga el archivo "hundir_flota_gui.py"
